# Resume alignment

Target resume framing:

**WebTrace: Multimodal Social & Code Mining Pipeline**  
Python, NLP, PyTorch, Data Mining, GitHub API

The implementation supports these research dimensions:

- reproducible collection and corpus construction from public web/social sources;
- repository URL and inline-code extraction;
- explicit taxonomy of code-sharing practices;
- optional OCR path for screenshots containing code;
- TF-IDF/classical ML baseline;
- transformer-based text classification;
- stratified/manual validation workflow;
- precision, recall, F1, confusion matrix, and error analysis.

Quantitative resume statements (for example, 50,000+ public posts, 3,000 manually validated items, or a particular macro-F1) should only be used after the corresponding collection/review/experiment has actually been completed.
